# Complytek CLM Cypress Tests

This repository contains automated test suites for **Complytek CLM**, built using [Cypress](https://www.cypress.io/).  
The tests ensure quality across different layers of the application, including **E2E workflows, API endpoints, and performance metrics**.

---

## 📑 Test Coverage

- **End-to-End (E2E) Tests**  
  Validate complete user journeys and business workflows.

- **API Tests**  
  Ensure backend endpoints and integrations function correctly.

- **Performance Tests**  
  Measure system performance and response times under different conditions.

---
